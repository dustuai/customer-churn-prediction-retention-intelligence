# Data Documentation

## Overview

This directory contains the datasets used in the Customer Churn Prediction & Retention Intelligence project.

## Dataset Files

### Original Dataset

**File:** `WA_Fn-UseC_-Telco-Customer-Churn.csv`

The source Telco Customer Churn dataset used as the starting point for the analysis.

### Cleaned Dataset

**File:** `telco_churn_clean.csv`

The processed customer dataset generated by the project's data preparation workflow.

Refer to the preprocessing code for the exact transformations performed.

### Customer Risk Output

**File:** `customer_risk_scores.csv`

The customer risk output generated by the project.

The implementation uses a risk-level field. Refer to the actual CSV schema for its precise name, categories, and other available columns. Do not assume that a numerical risk score is present just because it appears in the filename.

## Data Workflow

```text
Original dataset
      |
      v
Data inspection and cleaning
      |
      v
Processed customer dataset
      |
      v
Prediction and risk classification
      |
      v
Customer risk output
```

The exact sequence depends on the scripts and notebooks included in the project.

## Data Quality

The preprocessing workflow should be documented with the actual operations performed, such as data type correction, missing-value handling, duplicate checks, and feature preparation.

Do not claim a transformation was performed unless it is present in the code.

## Usage and Reproducibility

- Preserve the original dataset when permitted.
- Use the documented notebook or script workflow to regenerate processed data.
- Verify file paths before running the application or refreshing Power BI.
- Keep column names consistent across Python, SQL, and Power BI.
- Document any required external data source.

## Privacy and Licensing

Do not upload private customer records, credentials, or confidential business information.

Verify the source dataset's license and redistribution terms before committing the original CSV to a public repository.

## Limitations

The dataset may not represent all telecommunications customers. Model predictions and risk classifications should be interpreted within the context of the data and methodology.
