# Automated Tests

## Overview

This directory contains tests for the functionality implemented in the project.

## Test Coverage

Document the tests that actually exist, such as:

- Input validation
- Prediction function behavior
- Risk-level classification
- Retention recommendation rules
- Data preprocessing checks

## Running Tests

If the project uses pytest, install the required dependencies and run the following command from the repository root:

```bash
python -m pytest tests/
```

## Expected Behavior

Tests should validate defined behavior rather than assume that every prediction is correct.

Document known limitations and any required model artifacts or test fixtures.
